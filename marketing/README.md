1. Nichts wird ohne Pascals Freigabe veröffentlicht (`freigabe/README.md`).

3. Keine Zugangsdaten im Repo. Accounts legt Pascal selbst an.

## Wichtiger Hinweis zur Sichtbarkeit
Das Repository ist **öffentlich**, und `pages.yml` veröffentlicht bei jedem Push auf `main` das **ganze** Verzeichnis über GitHub Pages. Alles in `marketing/` (auch Entwürfe und Strategie) ist damit öffentlich lesbar. Entscheidung offen (siehe `docs/ki-team/ABSCHLUSSBERICHT.md`): so lassen, Entwürfe außerhalb des Repos halten oder Pages-Upload auf Spieldateien beschränken.
